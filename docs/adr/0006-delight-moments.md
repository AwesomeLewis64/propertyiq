# 6. Count-up, sparkle and pastel accents are limited

Status: accepted · 2026-10-08

- KPIs (IRR, NOI, DSCR and the rest of the metric row) count up from 0 the first time results appear. Later edits tween from the old value to the new one (~300ms). The accessible text is always the final formatted value.
- The sparkle fires once when a new analysis first opens to results with no errors. It never fires on validation errors.
- Pastel pink, violet and cyan appear only in the Analyze button's shine sweep and in the sparkle. Everything else uses the blue-to-indigo range.
