# Interface

PropertyIQ preserves its serif headings, navy actions, calm cards and local-data trust message.

Quick analysis appears first. Monthly planner sections use section headings, project subtitles, eight primary tools and More tools. Decision Lab uses labeled tabs. Charts have visible legends and numeric axes. Mobile quick analysis places a sticky IRR/multiple/DSCR summary before editable assumptions.

All styles use src/styles.css with shared design tokens. Screenshots and automated accessibility checks are generated by the browser suite.
