Scope: start page (#home) — Persuade. Quick analysis inherits tokens (Operate).
Audience: small multifamily investors/analysts checking a deal; action: paste deal details and start an analysis, or try the sample.

## Direction contract
THESIS: An Apple product page for a spreadsheet's worth of math: one enormous calm promise, then the product itself demonstrated as you scroll. Refuses the dashboard-template hero with stat tiles.
OWN-WORLD: White/near-white canvas (deep blue-black in dark), ink #0b1730-ish, one blue→indigo gradient reserved for the key phrase, frosted glass nav, soft layered shadows, 18–28px radii, system sans (SF/Segoe) with tight tracking. Pastels only in the primary button's border beam and the sparkle.
STORY: Visitor reads "Check if a multifamily deal works." understands it is free, local and transparent, pastes a deal or tries the sample.
FIRST VIEWPORT: Centered headline at clamp(48px, 8vw, 96px) with "deal works." in gradient, a short subtitle naming who it is for, the composer as a large raised card with Start an analysis as the primary action and Try a sample as the one secondary; slow low-contrast gradient glow behind.
FORM: Brief-pinned (Apple product page); concept-seed skipped because the user pinned the direction (brief wins). Seed key: none (pinned).
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
