# PropertyIQ decision tools — 2.1 beta

This local update adds fourteen of the fifteen requested ideas at a practical first-version level. Shared accounts remain deferred. It runs without a paid AI API. No actual Walnut figures were supplied for this update; the case study starts blank and the existing demo is fictional.

Open **Monthly & development** from the annual workspace, then use the sidebar. Project changes autosave in this browser; export an independent backup through **Portfolio & backups**.

## What was added

| Requested idea | Where to use it | Behavior and current limits |

## Important input conventions

- **Reconciliation:** NOI, scheduled debt and NOI DSCR use the selected start month and period length. Other metrics use the entire forecast. Annual IRR and dated XIRR are different. Use decimal fractions or percent text for spreadsheet IRR values. Absolute tolerance is in each metric's native units. Uploading previews values; only **Save mapped workbook benchmarks** adds them to the project and attaches the original file. Old stored benchmarks do not update when their source file changes. A values-only/recalculated-and-saved workbook avoids stale Excel results.
- **Renovation:** existing independent rent targets and explicit lease events stay in both comparison paths. If a rent increase is achievable without renovation, it is not counted as renovation benefit. Applying a plan enables selected renovations and disables unselected candidates; their entered costs remain editable. Payback is measured from the suggested start, including spending and lost rent. Later starts must still recover incremental cost within the entered hold.
- **Quote reserves:** the offer's reserve adds equally to initial funded cash and the minimum cash floor. It increases required initial equity and retains that cash until liquidation under the existing cash policy. This approximates a retained-cash reserve, without detailed lender-controlled release rules.
- **Operating detail:** use positive receipts and expense outflows. Imports append reviewed records and do not infer whether rows duplicate a previous import. Posting sets rent, other income and operating expense totals for the selected month; it preserves an existing actual statement's CapEx/debt totals or uses planned values if none exists. Collections do not update contractual rent, occupancy or loan principal automatically.
- **Deposits:** collected/refunded/released balances are tracked separately. Full gross sale receipts at closing include released deposits, so deposits are not additional income. Refunds are treated as restricted escrow movements. Escrow availability, legal terms and progress-payment agreements are not modeled.
- **Persistence:** optional decision-tool fields remain compatible with prior version-2 project backups. Browser storage is device-specific and can be cleared. Named history and downloaded backups are not a shared database or a tamper-proof audit log.
