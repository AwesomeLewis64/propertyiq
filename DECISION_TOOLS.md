# Decision tools

The Monthly planner exposes scenario comparison, renovation priorities, lender quotes and break-even analysis as labeled tabs in Decision Lab. Additional tools remain available under More tools or search.

Every comparison uses entered project assumptions; actual overrides are excluded from hypothetical scenario comparisons. Lender results are modeled capacity, not approval. Tax, waterfall and probability tools are simplified scenarios.

See METHODOLOGY.md for calculation conventions, RECONCILIATION.md for workbook validation, and CHANGELOG.md for historical release notes.
